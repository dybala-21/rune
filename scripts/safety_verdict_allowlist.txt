# Commands this repository has deliberately made easier to run.
#
# The safety job fails when a change lets a command through that the base
# branch stopped. That is the right default — it is the one regression a
# diff does not show — so a loosening has to be written down here, where a
# reviewer sees it next to the change that caused it.
#
# One JSON string per line, so a command containing a newline survives the
# round trip. Delete entries that no longer differ: a stale line hides the
# next regression on that command.
#
# ---------------------------------------------------------------------------
# 2026-08: `rm -f <glob>` was read as a recursive delete, because the flag
# pattern let the `r` of `-rf` be optional. Every bounded sweep was denied
# for want of a sandbox while `find … -delete` destroyed the same files at
# score zero, and agents met the denial one file at a time until the
# consecutive-call block cut them off half way. Measured on gbench2 across
# H6, C1 and C4, six pairs each: 9/18 -> 18/18, McNemar exact p=0.0039, with
# no run losing a file it was told to keep.
